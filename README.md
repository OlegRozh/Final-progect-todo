## Task‑tracker: веб‑приложение для управления персональными задачами
### Общая информация
Проект представляет собой REST API с графическим интерфейсом, написан на языке Go.

### Цель проекта: 
Создание планировщика задач с возможностью установки правил их автоматического повторения (ежедневно, еженедельно, ежемесячно, ежегодно). В будущих версиях планируется добавить дополнительные функции повторения.
**Выполненные задачи со звездочкой:**
Вынесен порт в переменную окружения.

### Запуск программы:

Проект организован согласно принципам чистой архитектуры, следуя рекомендациям от Uber https://github.com/sau00/uber-go-guide-ru/blob/master/style.md. Код разделён на изолированные пакеты внутри директории internal/, что делает его тестируемым и поддерживаемым.
### Состав пакетов:
**/cmd/main.go** - Главный пакет. Загружает переменные окружения, создаёт экземпляр хранилища (storage.New), инициализирует сервер и запускает его.

**/internal/api/handlers.go** - пакет для работы с http. TaskHandler — единый обработчик для эндпоинта /api/task, который маршрутизирует запросы по HTTP-методам к внутренним функциям GetTask, CreateTask, UpdateTask, DeleteTask. Также здесь определена утилита writeJSON для единообразной отправки JSON-ответов.

**/internal/api/nextDate.go** - в пакете реализована функция nextDate, которая возвращает дату следующего повторения задачи.

**/internal/api/task.go** - Пакет содержит одну единственную функцию, которая возвращает список из 50 последних задач.

**/internal/service/repeat.go** - Пакет содержит ключевую функцию NextDate, которая вычисляет следующую дату на основе правила. Также здесь реализована функция CheckDate, корректирующая дату задачи при создании/редактировании (перенос даты из прошлого на сегодня или на следующую дату).

**/internal/service/status.go** - Содержит функцию StatusDone, которая удаляет задачу, если она не повторяется. Если повторения задачи заданы, то обновляет дату.

**/internal/api/statusDone.go** - пакет содержит логику, которая меняет статус задачи на выполненную. Если повторения задачи не заданы, задача удаляется.

**/internal/server/server.go** - содержит структуру Server с полями для хранилища (через интерфейс storage.TaskStorage), порта и роутера. Конструктор New создаёт экземпляр сервера, метод SetupRoutes регистрирует все обработчики, а метод Start запускает HTTP-сервер на указанном порту.

**/internal/storage/interface.go** - Создан интерфейс для работы с БД для гибкости. Программа жестко не привязана к конкретной БД. Можно создать пакет postgres.go или mongodb.go и заменить бд без переписывания существующей реализации.

**/internal/storage/storage.go** - Пакет реализует логику работы с БД, в данном случае sqlite.

**/internal/structs/structs.go** - В пакете описаны структуры данных, одна для json который получает от клиента, другая для хранения данных БД. В процессе проектирования была необходииости вынести в отдельный пакет, чтобы не было ошибок цикличных импортов между пакетами api и storage.
